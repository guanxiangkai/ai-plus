# Artifact Plus 工程约定

- 本目录提供业务制品构建工具，不作为 Spring starter 或业务运行时依赖。
- 公开入口为 Gradle 插件、Maven 插件和独立验签 CLI；签名和混淆默认关闭。
- 输出使用独立目录，不覆盖输入 JAR；开启后任一步骤失败必须终止构建并清除本次保护输出。
- 签名覆盖最终 JAR 全部字节；验签信任外部配置的公钥，不接受制品自行提供的信任根。
- 密钥只从外部文件读取；不将密钥内容、映射表或未保护业务制品纳入交付包。
- 混淆必须保持 Boot 嵌套依赖的 ZIP 存储方式、公开契约和显式保留规则；不声称混淆等于加密。
- 模块版本来自根 gradle/module-versions.properties；构建和测试仅在 GitHub 托管 Linux CI 执行。
